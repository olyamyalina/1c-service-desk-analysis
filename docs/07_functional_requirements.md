# 07. Функциональные требования

## 1. Назначение раздела

Данный раздел содержит функциональные требования к системе «1С Service Desk».

Функциональные требования описывают, какие действия должна выполнять система для автоматизации процесса обработки IT-заявок, контроля SLA, учёта оборудования и формирования отчётности.

Раздел используется как основа для дальнейшего проектирования ER-модели, объектов 1С, use case диаграммы и тест-кейсов.

## 2. Область действия требований

Функциональные требования относятся к следующим функциональным блокам системы:

1. управление пользователями и ролями;
2. создание и регистрация IT-заявок;
3. обработка заявок IT-специалистами;
4. управление статусами заявок;
5. контроль SLA;
6. обработка уточнений;
7. связь заявок с оборудованием;
8. фиксация истории изменений;
9. уведомления пользователей;
10. отчётность;
11. администрирование справочников.

## 3. Приоритеты требований

Для требований используются следующие приоритеты:

| Приоритет | Значение |
|---|---|
| Must | обязательное требование для MVP |
| Should | важное требование, которое желательно реализовать после MVP |
| Could | дополнительное требование, которое можно реализовать при расширении проекта |

## 18. Вывод

Функциональные требования определяют, какие возможности должна предоставлять система «1С Service Desk».

На основе требований можно переходить к проектированию бизнес-правил, ER-модели, объектов 1С, use case диаграммы и тест-кейсов.

Требования с приоритетом Must формируют основу MVP проекта. Требования с приоритетом Should и Could могут быть реализованы в расширенной версии системы.
