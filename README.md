# 1С Service Desk: система обработки IT-заявок, контроля SLA и учёта оборудования

## Описание проекта

Проект представляет собой учебно-портфельный прототип информационной системы на платформе 1С для автоматизации работы внутренней IT-службы компании.

Система предназначена для регистрации и обработки IT-заявок от сотрудников, назначения исполнителей, контроля сроков реакции и решения по SLA, учёта оборудования, фиксации ремонтов и формирования управленческой отчётности для руководителя IT-отдела.

Проект разрабатывается с акцентом на два направления:

1. **IT-аналитика** — анализ предметной области, описание бизнес-процессов, выявление требований, моделирование данных, подготовка документации.
2. **1С** — проектирование объектов конфигурации, описание справочников, документов, регистров, бизнес-процессов, задач и отчётов.

## Цель проекта

Цель проекта — спроектировать и реализовать прототип 1С-системы, которая позволит централизованно обрабатывать IT-заявки, контролировать сроки выполнения, учитывать оборудование и анализировать работу IT-службы.

## Проблема

В компании обращения в IT-отдел поступают через разные каналы: устно, в мессенджерах, по телефону или электронной почте. Из-за отсутствия единой системы заявки могут теряться, сроки выполнения не контролируются, исполнители назначаются вручную, а руководитель IT-отдела не видит полной картины по загрузке специалистов и качеству обработки обращений.

## Основные функции системы

В рамках проекта планируется реализовать:

* регистрацию IT-заявок;
* классификацию заявок по категориям и приоритетам;
* назначение исполнителей;
* контроль статусов заявки;
* расчёт сроков реакции и решения;
* контроль нарушений SLA;
* учёт оборудования сотрудников;
* фиксацию ремонтов оборудования;
* хранение истории изменений заявки;
* формирование отчётов по заявкам, SLA, исполнителям и оборудованию.

## Основные роли пользователей

В системе выделяются следующие роли:

* сотрудник компании;
* специалист IT-отдела;
* руководитель IT-отдела;
* ответственный за оборудование;
* администратор системы.
